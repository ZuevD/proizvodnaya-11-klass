# Производная: увидеть и понять

Интерактивный учебный материал по алгебре и началам анализа для **11 класса**. Урок рассчитан примерно на 35–45 минут и помогает перейти от наглядного представления о скорости изменения к вычислению и применению производной.

## Что внутри

- **Четыре интерактивных опыта:** движение автомобиля и мгновенная скорость; приближение секущей к касательной; связанные графики функции и производной; поиск максимальной площади прямоугольника.
- Определение производной и пошаговый вывод для функции `f(x) = x²`.
- Таблица производных, правила вычисления и разобранные примеры.
- **Шесть упражнений** с проверкой числового ответа, подсказками и решениями.
- Памятка о типичных ошибках, включая нулевую производную без экстремума и отсутствие производной у `|x|` в нуле.

## Как открыть локально

Скачайте `index.html` и откройте его двойным кликом в современном браузере. Интернет, установка пакетов и сборка проекта не нужны: разметка, стили, графики и JavaScript находятся в одном файле.

Ползунки и кнопки позволяют управлять опытами и останавливать анимации. При включённом системном предпочтении уменьшенного движения анимации сразу переходят к конечному состоянию.

Кнопка **«Печать / сохранить PDF»** открывает печать браузера. При печати движение останавливается, а решения раскрываются.

## Публикация через GitHub Pages

После загрузки файлов в репозиторий откройте **Settings → Pages** и выберите публикацию из ветки **`main`**, папка **`/ (root)`**. Главная страница — `index.html`; файл `.nojekyll` отключает обработку Jekyll. Дополнительная сборка не требуется.

[Документация GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).
